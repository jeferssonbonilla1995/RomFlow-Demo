# 🏨 RoomFlow - Demo Visual

## Sistema Multi-Nicho | Moteles | Restaurantes | Facturación

---

## 🎯 ¿Qué es RoomFlow?

RoomFlow es un sistema comercial **YA funcionando en establecimientos reales en Ecuador**.

**No es un proyecto de práctica. Es un producto validado con clientes reales.**

---

## 📱 Modalidades

| Ícono | Modalidad | Funcionalidades clave |
|-------|-----------|----------------------|
| 🏨 | **Moteles** | Sensores magnéticos + Arduino / Detección automática de apertura / Cobro por tiempo / Servicios por habitación |
| 🍽️ | **Restaurantes** | Gestión de mesas / División de cuentas / Pedidos / Facturación |
| 🧾 | **Facturación** | Factura electrónica SRI / Conexión con Microplus / Reportes |

---

## 🔌 Integraciones especiales

### 🔹 Hardware (IoT)
- Sensores magnéticos conectados a Arduino
- Apertura de puerta → habitación ocupada → cobro automático

### 🔹 Contable
- Sincronizador directo con **Microplus**
- Fusión contable profesional sin trabajo manual

---

## 🛠️ Tecnologías

- ASP.NET Core (Backend)
- Blazor (Frontend interactivo)
- SQL Server (Base de datos)
- Arduino + Sensores magnéticos (IoT)
